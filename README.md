# Scale 12x

AI-Native Growth Studio — cinematic marketing experience built with Next.js.

## Overview

Scale 12x is a production homepage experience designed as one continuous narrative journey:

**Hero → Outcomes → Capabilities → Trust → Transformation → Voices → Conversation → Closing**

The interface combines editorial storytelling, Framer Motion choreography, and a Three.js particle atmosphere.

## Brand

**Scale 12x** — an elite AI-native growth studio helping ambitious companies scale exponentially.

- Scale Faster.
- Scale Smarter.
- Scale with AI.

Operating across London, New York, Dubai, San Francisco, and Riyadh. Estd. 2026.

## Stack

- **Next.js** 16 (App Router)
- **React** 19
- **TypeScript**
- **Tailwind CSS** 4
- **Framer Motion**
- **Three.js**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
